# Ahmed Gado Portfolio

A bilingual (English / Arabic) portfolio for Ahmed Mohsen Gado, built with plain HTML, CSS, and JavaScript. It has no framework or build step.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content and assets

- Update page sections in `index.html` and translated text, projects, skills, and experience in `app.js`.
- The styles are in `styles.css`.
- The supplied résumé is available at `public/assets/Ahmed-Gado-CV.pdf`.
- The supplied Pharmacy POS reference image is at `public/assets/pharmacy-pos.jpg`.
- Replace the LinkedIn and GitHub search links with direct profile URLs when available.
