# Ahmed Gado Portfolio

Bilingual (English / Arabic) Angular portfolio for Ahmed Mohsen Gado, built with Angular 20.

## Run locally

```bash
npm install
npm start
```

The production build is generated with `npm run build` in `dist/ahmed-gado-portfolio`.

## Content and assets

- Update project details, technical skills, and work history in `src/app/app.ts`.
- Update page content and contact links in `src/app/app.html`.
- The supplied résumé is available at `public/assets/Ahmed-Gado-CV.pdf`.
- The supplied Pharmacy POS reference image is at `public/assets/pharmacy-pos.jpg`.
- Replace the LinkedIn and GitHub search links with direct profile URLs when available.
